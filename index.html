Engenharia de Software & Sistemas Operacionais

Modelagem Orientada a Objetos (POO) do Simulador

O núcleo deste simulador foi projetado aplicando os pilares de Encapsulamento, Herança, Polimorfismo e Abstração utilizando classes nativas ES6+.

class Process Entidade / PCB

Representa o Bloco de Controle de Processo (PCB) simulado, mantendo estado e métricas individuais.

// Atributos
+ id, arrivalTime, burstTime
+ remainingTime, priority
+ state (NEW, READY, RUNNING...)
// Métodos
+ executeTick(currentTime)
+ calculateMetrics()
+ clone()
abstract class Scheduler Classe Base

Define a interface polimórfica para seleção de processos e controle de preempção.

// Atributos
+ name, isPreemptive, quantum
// Métodos Polimórficos
+ selectNextProcess(readyQueue)
+ shouldPreempt(current, queue, qUsed)
+ sortQueue(readyQueue)
class SimulationEngine Orquestrador

Controla o relógio discreto (ticks), admissão na fila de prontos, preempção e coleta de métricas.

// Atributos
+ currentTime, processes[]
+ readyQueue[], ganttHistory[]
+ contextSwitches, idleTime
// Métodos
+ step() // Avança 1 tick
+ runToCompletion()
+ getSummaryMetrics()

Hierarquia de Herança (Subclasses de Scheduler)

FCFSScheduler

Ordena por arrivalTime. Não preemptivo (shouldPreempt() = false).

SJFScheduler / SRTFScheduler

Ordena pelo menor remainingTime. SRTF sobrescreve shouldPreempt() para interromper se chegar job mais curto.

PriorityScheduler

Ordena por priority (1 = maior). Suporta modo Preemptivo ou Não Preemptivo via construtor.

RoundRobinScheduler

Fila circular FIFO com preempção por tempo quando quantumCounter >= quantum.
